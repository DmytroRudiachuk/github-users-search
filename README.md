# GitHub Users Search

A simple app that searches for GitHub users using the GitHub API.

## Features

- Fetches users from GitHub
- Displays user information
- Shows followers count
- Shows following count
- Shows user avatar
- Provides a link to the GitHub profile

## Technologies

- HTML
- CSS
- JavaScript
- Vite

## Installation

1. Install dependencies:
   `npm install`

2. Start the development server:
   `npm run dev`
